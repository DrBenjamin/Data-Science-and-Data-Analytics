# Data Science and Data Analytics - Skills Summary

**Course:** Data Science and Data Analytics (WS 2025/26)  
**Program:** International Business Management (B.A.)  
**Institution:** Hochschule Fresenius - University of Applied Sciences

## Course Learning Objectives

Upon successful completion of this course, students will be able to:

- Recognize important technological and methodological advancements in data science
- Distinguish between descriptive, predictive, and prescriptive analytics
- Demonstrate proficiency in classifying data and variables, collecting and managing data, and conducting comprehensive data evaluations
- Utilize R for effective data manipulation, cleaning, visualization, outlier detection, and dimensionality reduction
- Conduct sophisticated data exploration and mining techniques (including PCA, Factor Analysis, and Regression Analysis) to discover underlying patterns and inform decision-making
- Analyze and interpret causal relationships in data using regression analysis
- Evaluate and organize the implementation of a data analysis project in a business environment
- Communicate the results and effects of a data analysis project in a structured way

## 1. **Foundational Knowledge & Theory**

### Core Concepts
- **Data Science Definition**: Understanding data science as the field concerning techniques for extracting knowledge from diverse data, particularly 'big' data with volume, velocity, variety, value, and veracity attributes
- **Data Analytics**: Systematic process of examining data using statistical, computational, and domain-specific methods to extract insights and support decision-making
- **Business Analytics**: Science of posing and answering data questions related to business using statistics, data management, visualization, and machine learning

### Academic Disciplines Integration
- **Informatics/Information Systems**: Information processing, storage, retrieval systems, database design, data modeling
- **Computer Science**: Algorithms, data structures, systems design, machine learning, distributed computing
- **Mathematics**: Linear algebra, calculus, optimization, discrete mathematics, matrix operations
- **Statistics & Econometrics**: Inference, modeling, causal analysis, hypothesis testing, regression analysis
- **Social Science & Behavioral Sciences**: Contextual interpretation, experimental design, ethical considerations

### Types of Analytics
- **Descriptive Analytics**: "What happened?" - Historical data analysis and reporting
- **Predictive Analytics**: "What is likely to happen?" - Forecasting and prediction models
- **Prescriptive Analytics**: "What should we do?" - Optimization and recommendation systems

## 2. **Data Competencies**

### Data Types & Classification
- **Cross-sectional data**: Data collected at a single point in time
- **Panel (longitudinal) data**: Data collected over multiple time periods for the same entities
- **Time-series data**: Data points collected or recorded at time-ordered intervals
- **Geo-referenced/spatial data**: Data with geographic location information
- **Streaming/real-time data**: Continuously generated data requiring immediate processing

### Variable Types
- **Continuous (interval/ratio)**: Numerical data with meaningful intervals or ratios
- **Count**: Discrete numerical data representing frequencies or quantities
- **Ordinal**: Categorical data with natural ordering
- **Categorical (nominal/binary)**: Qualitative data without natural ordering
- **Compositional or hierarchical structures**: Complex data relationships

### Data Collection Competencies
- **Source Identification**: Systematically identify internal and external data sources
- **Data Acquisition Methods**: APIs, database queries, surveys, sensors, web scraping, third-party partnerships
- **Quality Assessment**: Evaluate data relevance, accuracy, completeness, and reliability
- **Governance Framework**: Data provenance, licensing, ethical compliance (GDPR), regulatory requirements

### Data Management
- **Organize**: Schema design, naming conventions, data architecture
- **Clean**: Resolve duplicates, inconsistencies, missing values
- **Convert**: Type casting, normalization, encoding, transformation
- **Curate**: Maintain lineage, documentation, metadata management
- **Preserve**: Backups, versioning, retention policies, archival strategies

## 3. **Programming & Technical Skills**

### R Programming Environment
- **Core tidyverse Packages**:
  - `dplyr`: Data manipulation (filter, mutate, summarize, joins)
  - `tidyr`: Data reshaping (pivoting, nesting, separating, unnesting)
  - `ggplot2`: Grammar-based data visualization
  - `readr`: Data import and export
  - `purrr`: Functional programming and iteration
  - `stringr`: String manipulation
  - `forcats`: Factor handling

### Python Integration
- **Environment Setup**: Conda environments, package management
- **Key Libraries**: pandas, jupyter, data analysis tools
- **R-Python Integration**: Using reticulate for seamless workflow

### Development Tools
- **Version Control**: Git workflows and collaborative development
- **Documentation**: Quarto for reproducible reporting and analysis
- **Environment Management**: renv for R package management, conda for Python

## 4. **Statistical & Analytical Methods**

### Exploratory Data Analysis (EDA)
- **Structured EDA Workflow**: Question → Visualize → Quantify → Refine
- **Descriptive Statistics**: Measures of central tendency, variability, distribution
- **Data Visualization Principles**: Appropriate encodings, clarity, comparison support

### Advanced Analytical Techniques
- **Outlier Detection**:
  - Rule-based methods (IQR, z-scores)
  - Robust statistics (median, MAD)
  - Model-based detection (Mahalanobis distance, clustering residuals)

- **Dimensionality Reduction**:
  - Principal Component Analysis (PCA) for variance structure
  - Factor Analysis for latent constructs
  - Trade-offs between interpretability and compression

- **Data Mining & Pattern Discovery**:
  - Clustering techniques (k-means, hierarchical)
  - Association rule mining
  - Pattern recognition algorithms

### Regression Analysis & Causal Inference
- **Regression Fundamentals**: Linear, multiple, logistic regression
- **Causal Analysis**: Distinguishing association vs. causation
- **Model Assumptions**: Linearity, independence, homoskedasticity, exogeneity
- **Model Validation**: Robustness checks, sensitivity analysis
- **Interpretation**: Coefficient interpretation, marginal effects

### Operational Analytics

- **Forecasting**: Time series analysis, demand planning (ARIMA, exponential smoothing)

- **Pricing Strategy**: Price elasticity analysis, revenue optimization
- **Market Intelligence**: Competitive analysis, market trend identification
- **Financial Analysis**: Ratio analysis, variance analysis, predictive financial modeling

## Assessment Areas

Students will be evaluated on their ability to:

1. **Theoretical Understanding**: Demonstrate comprehension of data science principles and methodologies
2. **Technical Proficiency**: Apply R programming skills for data analysis tasks
3. **Analytical Thinking**: Conduct appropriate statistical analyses and interpret results
4. **Business Application**: Connect analytical techniques to real-world business problems
5. **Communication**: Present findings clearly and effectively to various audiences
6. **Project Management**: Successfully implement and document a complete data analysis project
